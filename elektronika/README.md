# Elektronika

Osobní elektronické projekty, zapojení a zkušenosti Jiřího Nováka. Tato sekce patří do stejného repozitáře jako 3D modely; není součástí TechTools Brainu.

**Sem patří všechny další osobní elektronické projekty, i když vůbec nesouvisejí s 3D tiskem.** Každý nový projekt založit v `elektronika/<nazev>/` s vlastním `README.md` a přidat jej do indexu níže. Uchovat tu celý propojený kontext: zadání, součástky a odkazy do inventáře, zapojení, zdroje programu, postupy, výsledky, neznámé a další kroky.

**Výjimka pro existující autíčko:** jeho firmware zatím zůstává v `models/jednoduche-auticko/firmware/prvni-motor/`, aby se zachovala zavedená cesta. Přehled elektroniky na něj odkazuje; tato historická výjimka neurčuje umístění nových projektů.
