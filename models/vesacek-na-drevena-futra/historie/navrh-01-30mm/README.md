# Historie: první návrh s 30mm hlavním háčkem

Toto je archiv původního vizuálního návrhu před Jiřího požadavkem udělat hlavní háček delší a mohutnější. Hlavní háček vyčníval 30 mm od čela destičky, celek 37 mm od futer; kořen měl Ø 17 mm. **Není to aktuální varianta ani připravená tisková podložka.**

Archiv obsahuje původní zdrojové makro, FCStd, STL, kontrolní JSON a přehledový CAD náhled. Pro aktuální model používej soubory v nadřazené složce modelu a aktuální 3MF v `rozlozeni/`.
