# Historická reference: samotné tělo 10 mm

Původní geometricky ověřený návrh 570 ×20 ×10 mm bez lepicího lože a s nominální nulovou vůlí spojů. Nahrazen aktuální revizí v nadřazené modelové složce: těla8 mm + nominální2mm lože a skutečné lepicí mezery. Tuto historii netisknout jako aktuální montážní řešení. Soubory jsou uchované pro dohledatelnost, ne jako aktuální stav.
